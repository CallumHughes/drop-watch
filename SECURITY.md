# Security policy

## Reporting a vulnerability

Report it privately through
[GitHub's vulnerability reporting](https://github.com/CallumHughes/drop-watch/security/advisories/new),
not in a public issue or PR. Include the affected version or commit, steps to
reproduce, and the impact you expect.

The fix ships before the advisory is published, and you're credited unless
you'd rather not be.

## Supported versions

Only `main` and the `latest` images on GHCR get fixes.
